# Travel Planner

A cross-platform mobile application developed using React Native and Expo, where users can plan trips, organise itineraries, manage trip members, and track shared expenses.

## About

Travel Planner is a mobile application designed to bring different parts of trip planning into one place.

Users can create and manage trips, organise itineraries, connect with other users, manage trip members, track shared expenses, and receive notifications.

## Key Features

- User registration and authentication
- User profile management
- Friend search and friend requests
- Trip creation and management
- Trip member management
- Itinerary planning
- Shared expense tracking
- Search functionality
- Notifications

## Technical Implementation

Travel Planner was developed as a cross-platform mobile application using React Native and Expo, with Supabase providing authentication and database functionality.

### Mobile Interface

The application was developed using React Native and Expo with reusable screens and components for different parts of the travel planning experience.

Navigation between screens allows users to access their trips, itineraries, expenses, notifications, and profile features through the mobile interface.

### Authentication & User Profiles

Users can register and log in to the application and manage their profile information.

Supabase Authentication is used to handle user accounts and authentication, with user-related data connected to the application's database.

### Friends & Notifications

Users can search for other users and send friend requests through the application.

Friend requests and other updates can be surfaced through the notification system, supporting interaction between users before and during trip planning.

### Trip, Itinerary, Expense & Member Management

Users can create and manage trips, organise itineraries, add and manage trip members, and track shared expenses within each trip.

These features bring key parts of trip planning together, allowing users to manage travel plans, activities, participants, and expenses in one place.
